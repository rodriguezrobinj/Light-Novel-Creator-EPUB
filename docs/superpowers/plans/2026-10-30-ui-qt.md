# UI nueva en Qt — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sustituir la ventana tkinter por una en PySide6 con la distribución B, tema Fluent claro/oscuro,
pantalla vacía guiada y las mismas funciones.

**Architecture:** `qtk.py` da a la lógica actual la API de Tk que ya usa (Treeview, Text, messagebox,
filedialog) sobre widgets Qt; así `App` y `TextEditor` se portan en `app.py` cambiando la construcción de
widgets, no la lógica. `theme.py` pone Fusion + paleta + QSS. El proceso de trabajo no cambia.

**Tech Stack:** Python 3.14, PySide6 (`pyside6-essentials==6.12.0`), PyMuPDF, PyInstaller.

**Spec:** `docs/superpowers/specs/2026-10-30-ui-qt-design.md`

## Global Constraints

- Todo texto visible en español con tildes; comentarios y docstrings en español, cortos, dicen el porqué.
- Nombre visible «Light Novel Creator»; `PDF a EPUB.exe`, `%APPDATA%\PDF a EPUB\ajustes.json` y
  `.lnepub.json` no cambian.
- `convert.py` no cambia. El trabajo pesado sigue en `multiprocessing.Process` (`_worker`), nunca en hilos.
- Tests: `.venv/Scripts/python.exe test_convert.py`, con `QT_QPA_PLATFORM=offscreen` puesto por el propio
  archivo antes de importar Qt. No correr tests y build a la vez.
- Mismo funcionamiento en Windows 10 y 11: estilo Fusion, letra Segoe UI.
- Commits en inglés, Conventional Commits, en la rama `feat/qt-ui`.

## Review Focus

1. Pantalla 1366×768 con barra de tareas: «Generar EPUB» y la barra inferior siempre visibles (la ventana
   cabe en `availableGeometry`). Test: geometría inicial dentro de la pantalla disponible.

   el `.tmp`. Test: `test_window_runs_work_in_another_process` y el de cerrar con editor, portados.
3. `ajustes.json` escrito a mano con `theme` inválido: arranca con «Sistema». Test en la tarea 2.
4. Soltar algo que no es PDF (o varios archivos) sobre la ventana: se ignora salvo el primer `.pdf`. Test
   en la tarea 4.
5. Modo oscuro: colores de la lista y del editor legibles (sin `#555555` sobre fondo oscuro). Test: los
   colores de tipo salen de `theme.kind_colors(dark)` y difieren entre claro y oscuro.

**Interfaces (Produces):**
- `qtk.app()` → la `QApplication` única (la crea si no existe).
- `qtk.after(ms, fn, *args)` → `QTimer` de un disparo; `qtk.cancel(timer)`.
- `qtk.pump()` → `QApplication.processEvents()` (sustituye a `root.update()` en los tests).
- `qtk.messagebox`: `showinfo/showwarning/showerror(title, message, parent=None)`,
  `askyesno(...) -> bool`, `askyesnocancel(...) -> bool | None`. Botones «Sí», «No», «Cancelar», «Aceptar».
- `qtk.filedialog`: `askopenfilename(filetypes=(), initialdir=None, title=…) -> str`,
  `askopenfilenames(...) -> tuple[str]`, `asksaveasfilename(defaultextension, filetypes, initialdir,
  initialfile) -> str`, `askdirectory(initialdir=None, title=…) -> str`. `""`/`()` al cancelar.
  `[("PDF", "*.pdf")]` → filtro `"PDF (*.pdf)"`.
- `qtk.RowList(QTreeWidget)`: `RowList(columns: tuple[str], headings: dict, widths: dict)`;
  `insert("", "end", iid, values, tags) -> iid`, `delete(*iids)`, `get_children() -> tuple[str]`,
  `exists(iid)`, `set(iid, col) -> str`, `set(iid, col, value)`, `item(iid, tags=(tag,))`,
  `tag_configure(tag, font: QFont = None, foreground: str = None)`, `selection() -> tuple[str]`,
  `selection_set(iid)`, `see(iid)`, `index(iid) -> int`, `bbox(iid, col) -> (x, y, w, h)` en coordenadas
  del viewport, `column_at(x) -> "#1"…`, `row_at(y) -> iid | ""`. Señal `selected` al cambiar la selección.
- `qtk.TextBox(QPlainTextEdit)`: índices Tk (`"L.C"`, `"L.end"`, `"insert"`, `"end"`, `"sel.first"`,
  `"sel.last"`, sufijos `+Nc`, `-Nc`, ` linestart`, ` lineend`, en cadena); `get(a, b=None)`,
  `insert(index, text, tags=())`, `delete(a, b=None)`, `index(i) -> "L.C"`, `mark_set("insert", i)`,
  `search(needle, start) -> "L.C" | ""`, `tag_add/tag_remove(tag, a, b)`, `tag_names(i) -> tuple`,
  `tag_ranges(tag)`, `tag_configure(tag, foreground=, background=, underline=, overstrike=, weight=,
  italic=, size=)`, `edit_undo()`, `edit_reset()`, `group()` (context manager: un paso de deshacer).
  `"sel"` es la selección; `src<k>` va en el formato de los caracteres (se mueve con el texto); los demás
  tags son `ExtraSelection` sobre `QTextCursor` (siguen al texto y no entran en deshacer).

def test_qtk_rowlist_works_like_treeview():
    import qtk
    tree = qtk.RowList(("inc", "title"), {"inc": "Tipo", "title": "Título"}, {"inc": 80, "title": 200})
    for k, title in ((0, "Uno"), (3, "Dos"), (5, "Tres")):
        tree.insert("", "end", iid=str(k), values=("Capítulo", title), tags=("chapter",))
    tree.set("3", "title", "Dos bis")
    tree.selection_set("5")
    seen = (tree.get_children(), tree.set("3", "title"), tree.selection(), tree.index("5"), tree.exists("4"))
    tree.delete("0")
    assert seen == (("0", "3", "5"), "Dos bis", ("5",), 2, False), seen
    assert tree.get_children() == ("3", "5")
