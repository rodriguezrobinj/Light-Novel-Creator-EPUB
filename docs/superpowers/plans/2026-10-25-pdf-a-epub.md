# Conversor PDF a EPUB — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Programa de escritorio con ventana `tkinter` que convierte PDFs de novelas ligeras en EPUB con texto fluido, capítulos revisables e ilustraciones.

**Architecture:** `convert.py` contiene la lógica pura. `analyze()` lee el PDF con PyMuPDF y produce un `Book` con bloques (párrafo, título, imagen, separador) y los índices de los títulos candidatos. `write_epub()` escribe el EPUB 3 con `zipfile`. `app.py` es la ventana: llama a ambas funciones en un hilo y muestra los capítulos para revisarlos.

**Tech Stack:** Python 3.14, PyMuPDF 2.0 (`pymupdf`), `tkinter`/`ttk`, `zipfile`. Sin frameworks de pruebas.

**Spec:** `docs/superpowers/specs/2026-10-25-pdf-a-epub-design.md`

## Global Constraints

- Única dependencia externa: `pymupdf==2.0`, instalada en `.venv` (ya creado e ignorado por git).
- Todos los comandos se ejecutan desde la raíz del proyecto con `.venv/Scripts/python` (Windows, Git Bash).
- Mensajes, etiquetas y textos de error para el usuario, en español.
- Los PDFs (`Novelas PDF/`, `*.pdf`) y los EPUB (`*.epub`) nunca se commitean: ya están en `.gitignore`.
- Pruebas: un solo archivo, `test_convert.py`, ejecutable con `python test_convert.py`, solo con `assert`.
- El EPUB debe tener `mimetype` como primera entrada del zip, sin comprimir y con contenido `application/epub+zip`.
- Fuera de alcance: OCR, agregar capítulos a mano, empaquetar `.exe`.

## Review Focus

1. **Página de índice del PDF** ("Contenido", líneas `.....  12`): no debe generar capítulos falsos. Lo cubre `test_analyze` (página 1 del PDF sintético).
2. **Párrafo normal que empieza con palabra clave** ("Parte de mí…"): no debe ser capítulo. Lo cubre `test_analyze` (párrafo "Parte de mi…").
3. **Caracteres `&`, `<`, `>` en el texto**: el XHTML debe seguir bien formado. Lo cubren `test_analyze` (`&amp;`, `&lt;`) y `test_write_epub` (parsea todo XML del zip).
4. **Texto justificado partido en varios spans en la misma línea**: debe salir como una sola línea y conservar la cursiva. Lo cubre `test_analyze` (línea "Ella penso" + span en cursiva).
5. **PDF escaneado sin texto**: debe dar un error claro, no un EPUB vacío. Lo cubre `test_scanned_pdf_is_rejected`.

Datos medidos en los PDFs de muestra que justifican los umbrales (ver spec, sección "Análisis del PDF"):
- Separación entre párrafos / interlineado: 1,43 (World Project) y 1,84 (Astral). Umbral: 1,3.
- La caja (`bbox`) de los spans en Cambria mide unos 67 pt en una línea de 12 pt: por eso se agrupa por `span["origin"][1]`.

def line(text, width):
    """Rellena text hasta width caracteres: en Courier todas las líneas llenas acaban en el mismo x."""
    return (text + " relleno" * 20)[:width]


def add_page(doc, number, lines):
    """lines: [(x, y, texto, tamaño, fuente)]. Añade encabezado y pie como haría Word."""
    p = doc.new_page(width=595, height=842)
    p.insert_text((72, 40), HEADER, fontsize=10, fontname="hebo")
    p.insert_text((72, 815), f"{FOOTER}   {number}", fontsize=10, fontname="helv")
    for x, y, text, size, font in lines:
        p.insert_text((x, y), text, fontsize=size, fontname=font)
    return p

```python
"""Convierte PDFs de novelas ligeras en EPUB con texto fluido."""
import collections
import html
import os
import re
import uuid
import zipfile
from dataclasses import dataclass
from datetime import datetime, timezone
from pathlib import Path

import pymupdf

BAND = 0.12     # franja superior/inferior (fracción de la altura) donde viven encabezados y pies
REPEAT = 0.30   # fracción de páginas en que una línea debe repetirse para ser encabezado o pie
KEYWORDS = re.compile(
    r"(cap[ií]tulo|pr[oó]logo|ep[ií]logo|interludio|historia paralela|palabras de cierre"
    r"|extra|parte|chapter|prologue|epilogue|afterword|interlude)\b", re.I)
TOC_TITLE = re.compile(r"(contenidos?|[ií]ndice|tabla de contenidos?|contents|table of contents):?", re.I)
DOT_LEADER = re.compile(r"\.{4,}\s*\d+$")
SCENE_BREAK = re.compile(r"[\s☆★*＊◆◇●○■□♦♢※✦✧❖◈•·#~◎◯]+")
END_PUNCT = (".", "!", "?", "…", '"', "'", "»", "”", "’", ":", ")")
BAD_XML = re.compile("[\x00-\x08\x0b\x0c\x0e-\x1f￾￿­]")


@dataclass
class Row:
    text: str     # texto plano
    html: str     # texto con <i>/<b>, escapado para XHTML
    x0: float
    x1: float
    y: float      # línea base
    size: float
    bold: bool


@dataclass
class Block:
    kind: str           # "p" | "heading" | "image" | "break"
    page: int           # página de origen (empieza en 1)
    html: str = ""
    image: bytes = b""  # JPEG si kind == "image"


@dataclass
class Book:
    title: str
    author: str
    cover: bytes        # JPEG
    blocks: list
    candidates: list    # índices en blocks de los títulos de capítulo detectados


def _bold(s):
    return bool(s["flags"] & pymupdf.TEXT_FONT_BOLD) or "bold" in s["font"].lower()


def _italic(s):
    font = s["font"].lower()
    return bool(s["flags"] & pymupdf.TEXT_FONT_ITALIC) or "italic" in font or "oblique" in font


def _row(spans):
    spans.sort(key=lambda s: s["origin"][0])
    texts, parts = [], []
    for s in spans:
        t = BAD_XML.sub("", s["text"])
        if texts and not texts[-1].endswith(" ") and not t.startswith(" "):
            texts.append(" ")
            parts.append(" ")
        texts.append(t)
        part = html.escape(t, quote=False)
        if _italic(s):
            part = f"<i>{part}</i>"
        if _bold(s):
            part = f"<b>{part}</b>"
        parts.append(part)
    main = max(spans, key=lambda s: len(s["text"].strip()))
    return Row(" ".join("".join(texts).split()), "".join(parts).strip(),
               spans[0]["bbox"][0], spans[-1]["bbox"][2], spans[0]["origin"][1],
               round(main["size"], 1), all(_bold(s) for s in spans))


def _rows(page):
    """Agrupa los spans por línea base: el texto justificado parte una línea en varios spans."""
    spans = [s for b in page.get_text("dict")["blocks"] for line in b.get("lines", [])
             for s in line["spans"] if s["text"].strip()]
    rows, group = [], []
    for s in sorted(spans, key=lambda s: s["origin"][1]):
        if group and abs(s["origin"][1] - group[0]["origin"][1]) > 2:
            rows.append(_row(group))
            group = []
        group.append(s)
    if group:
        rows.append(_row(group))
    return rows


def _norm(text):
    return re.sub(r"\d+", "#", " ".join(text.lower().split()))


def _strip_margins(pages, heights):
    """Quita encabezados y pies: líneas de las franjas que se repiten en muchas páginas."""
    def in_band(r, h):
        return r.y < h * BAND or r.y > h * (1 - BAND)

    counts = collections.Counter()
    for rows, h in zip(pages, heights):
        counts.update({_norm(r.text) for r in rows if in_band(r, h)})
    repeated = {k for k, n in counts.items() if n >= max(2, REPEAT * len(pages))}
    repeated.add("#")  # números de página sueltos
    return [[r for r in rows if not (in_band(r, h) and _norm(r.text) in repeated)]
            for rows, h in zip(pages, heights)]


def _is_heading(r, body):
    if len(r.text) > 120:
        return False
    return r.size >= body * 1.3 or (r.bold and (r.size >= body * 1.1 or bool(KEYWORDS.match(r.text))))


def _is_toc(rows):
    return bool(TOC_TITLE.fullmatch(rows[0].text)) or sum(bool(DOT_LEADER.search(r.text)) for r in rows) >= 3


def _first_group(rows):
    """Primer título de una página que solo tiene títulos (el resto son duplicados decorativos)."""
    group = [rows[0]]
    for r in rows[1:]:
        if abs(r.size - rows[0].size) >= 0.5:
            break
        group.append(r)
    return group


def _image_coverage(page):
    area = page.rect
    return sum(abs(pymupdf.Rect(i["bbox"]) & area) for i in page.get_image_info()) / abs(area)


def _render(page):
    return page.get_pixmap(dpi=150).tobytes("jpg", jpg_quality=85)


def _join(a, b):
    if re.search(r"\w-$", a) and b[:1].islower():
        return a[:-1] + b
    return f"{a} {b}"


def analyze(pdf_path, progress=None):
    """Lee el PDF y lo devuelve como bloques, con los títulos de capítulo candidatos."""
    try:
        doc = pymupdf.open(pdf_path)
    except Exception as e:
        raise ValueError(f"No se pudo abrir el PDF: {e}") from e
    with doc:
        if doc.needs_pass:
            raise ValueError("El PDF está protegido con contraseña.")
        n = doc.page_count
        pages = []
        for i, page in enumerate(doc):
            pages.append(_rows(page))
            if progress:
                progress(i + 1, 2 * n)
        pages = _strip_margins(pages, [page.rect.height for page in doc])
        if not any(pages):
            raise ValueError("El PDF no tiene texto (parece escaneado). Hace falta OCR, que no está soportado.")

        sizes = collections.Counter(r.size for rows in pages for r in rows for _ in r.text)
        body = sizes.most_common(1)[0][0]
        gaps = collections.Counter()
        indents = total = 0
        for rows in pages:
            normal = [r for r in rows if r.size == body]
            gaps.update(round(b.y - a.y) for a, b in zip(normal, normal[1:]) if 0 < b.y - a.y < body * 3)
            if normal:
                left = min(r.x0 for r in normal)
                total += len(normal)
                indents += sum(r.x0 > left + body * 0.8 for r in normal)
        line_gap = gaps.most_common(1)[0][0] if gaps else body * 1.2
        indent_style = indents > total * 0.05  # los párrafos se marcan con sangría

        blocks = []
        para, short, last_text = None, False, ""
        for i, (page, rows) in enumerate(zip(doc, pages)):
            num = i + 1
            if progress:
                progress(n + num, 2 * n)
            headings = [r for r in rows if _is_heading(r, body)]
            # ponytail: solo ilustraciones a página completa; las pequeñas dentro del texto se descartan
            if not headings and sum(len(r.text) for r in rows) < 200 and _image_coverage(page) > 0.5:
                blocks.append(Block("image", num, image=_render(page)))
                para = None
                continue
            if not rows or _is_toc(rows):
                continue
            if len(headings) == len(rows):
                rows = _first_group(rows)
            normal = [r for r in rows if not _is_heading(r, body)]
            left = min((r.x0 for r in normal), default=0)
            right = max((r.x1 for r in normal), default=0)
            prev = None
            for r in rows:
                if _is_heading(r, body):
                    if prev is not None and _is_heading(prev, body) and abs(prev.size - r.size) < 0.5:
                        blocks[-1].html += " " + html.escape(r.text)
                    else:
                        blocks.append(Block("heading", num, html.escape(r.text)))
                    para = None
                elif SCENE_BREAK.fullmatch(r.text):
                    blocks.append(Block("break", num))
                    para = None
                else:
                    indented = r.x0 > left + body * 0.8
                    if para is None or indented or short:
                        new = True
                    elif prev is None:  # primera línea de la página: ¿sigue el párrafo anterior?
                        new = not indent_style and last_text.endswith(END_PUNCT)
                    else:
                        new = r.y - prev.y > line_gap * 1.3
                    if new:
                        para = Block("p", num, r.html)
                        blocks.append(para)
                    else:
                        para.html = _join(para.html, r.html)
                    short = r.x1 < right - (right - left) * 0.2
                    last_text = r.text
                prev = r

        if blocks and blocks[0].kind == "image" and blocks[0].page == 1:
            cover = blocks.pop(0).image
        else:
            cover = _render(doc[0])

        outline = [(title, p) for level, title, p in doc.get_toc() if level == 1]
        if outline:
            chosen = set()
            for title, p in outline:
                k = next((k for k, b in enumerate(blocks) if b.kind == "heading" and b.page == p), None)
                if k is None:
                    k = next((k for k, b in enumerate(blocks) if b.page >= p), len(blocks))
                    blocks.insert(k, Block("heading", p, html.escape(title)))
                chosen.add(id(blocks[k]))
            candidates = [k for k, b in enumerate(blocks) if id(b) in chosen]
        else:
            candidates = [k for k, b in enumerate(blocks) if b.kind == "heading"]

        meta = doc.metadata or {}
        return Book(meta.get("title") or Path(pdf_path).stem, meta.get("author") or "", cover, blocks, candidates)

def _xhtml(title, body, lang):
    return ('<?xml version="1.0" encoding="utf-8"?>\n<!DOCTYPE html>\n'
            f'<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops"'
            f' lang="{lang}" xml:lang="{lang}">\n'
            f'<head><meta charset="utf-8"/><title>{html.escape(title)}</title>'
            '<link rel="stylesheet" type="text/css" href="style.css"/></head>\n'
            f'<body>\n{body}\n</body>\n</html>\n')


def write_epub(book, chapters, out_path, lang="es"):
    """Escribe el EPUB. chapters: [(índice de bloque, título)] elegidos por el usuario."""
    starts = dict(chapters)
    sections = []  # [título, es_capítulo, bloques]
    for k, b in enumerate(book.blocks):
        if k in starts:
            sections.append([starts[k], True, []])
        else:
            if not sections:
                sections.append(["Inicio", False, []])
            sections[-1][2].append(b)

    files, images = {}, {}
    for n, (title, is_chapter, blocks) in enumerate(sections, 1):
        parts = [f"<h1>{html.escape(title)}</h1>"] if is_chapter else []
        for b in blocks:
            if b.kind == "image":
                src = f"img/p{b.page:04d}.jpg"
                images[src] = b.image
                parts.append(f'<div class="img"><img src="{src}" alt=""/></div>')
            elif b.kind == "break":
                parts.append('<p class="brk">* * *</p>')
            else:
                parts.append(f"<p>{b.html}</p>")
        files[f"sec{n:03d}.xhtml"] = _xhtml(title, "\n".join(parts), lang)

    uid = f"urn:uuid:{uuid.uuid4()}"
    title = html.escape(book.title)
    creator = f"<dc:creator>{html.escape(book.author)}</dc:creator>\n" if book.author else ""
    modified = datetime.now(timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ")
    manifest = [
        '<item id="nav" href="nav.xhtml" media-type="application/xhtml+xml" properties="nav"/>',
        '<item id="ncx" href="toc.ncx" media-type="application/x-dtbncx+xml"/>',
        '<item id="css" href="style.css" media-type="text/css"/>',
        '<item id="cover-image" href="cover.jpg" media-type="image/jpeg" properties="cover-image"/>',
        '<item id="cover" href="cover.xhtml" media-type="application/xhtml+xml"/>',
    ]
    manifest += [f'<item id="s{k}" href="{name}" media-type="application/xhtml+xml"/>' for k, name in enumerate(files)]
    manifest += [f'<item id="i{k}" href="{src}" media-type="image/jpeg"/>' for k, src in enumerate(images)]
    spine = ['<itemref idref="cover"/>'] + [f'<itemref idref="s{k}"/>' for k in range(len(files))]
    manifest_xml, spine_xml = "\n".join(manifest), "\n".join(spine)
    opf = f"""<?xml version="1.0" encoding="utf-8"?>
<package xmlns="http://www.idpf.org/2007/opf" version="3.0" unique-identifier="uid">
<metadata xmlns:dc="http://purl.org/dc/elements/1.1/">
<dc:identifier id="uid">{uid}</dc:identifier>
<dc:title>{title}</dc:title>
{creator}<dc:language>{lang}</dc:language>
<meta property="dcterms:modified">{modified}</meta>
<meta name="cover" content="cover-image"/>
</metadata>
<manifest>
{manifest_xml}
</manifest>
<spine toc="ncx">
{spine_xml}
</spine>
</package>
"""
    entries = [(name, sec[0]) for name, sec in zip(files, sections)]
    items = "\n".join(f'<li><a href="{name}">{html.escape(t)}</a></li>' for name, t in entries)
    nav = _xhtml("Índice", f'<nav epub:type="toc" id="toc"><h1>Índice</h1><ol>\n{items}\n</ol></nav>', lang)
    points = "\n".join(
        f'<navPoint id="n{k}" playOrder="{k}"><navLabel><text>{html.escape(t)}</text></navLabel>'
        f'<content src="{name}"/></navPoint>' for k, (name, t) in enumerate(entries, 1))
    ncx = f"""<?xml version="1.0" encoding="utf-8"?>
<ncx xmlns="http://www.daisy.org/z3986/2005/ncx/" version="2005-1">
<head><meta name="dtb:uid" content="{uid}"/></head>
<docTitle><text>{title}</text></docTitle>
<navMap>
{points}
</navMap>
</ncx>
"""
    cover = _xhtml(book.title, '<div class="img"><img src="cover.jpg" alt="Portada"/></div>', lang)

    tmp = f"{out_path}.tmp"
    try:
        with zipfile.ZipFile(tmp, "w", zipfile.ZIP_DEFLATED) as z:
            z.writestr("mimetype", "application/epub+zip", compress_type=zipfile.ZIP_STORED)
            z.writestr("META-INF/container.xml", CONTAINER)
            z.writestr("OEBPS/content.opf", opf)
            z.writestr("OEBPS/nav.xhtml", nav)
            z.writestr("OEBPS/toc.ncx", ncx)
            z.writestr("OEBPS/style.css", CSS)
            z.writestr("OEBPS/cover.xhtml", cover)
            z.writestr("OEBPS/cover.jpg", book.cover)
            for name, text in files.items():
                z.writestr(f"OEBPS/{name}", text)
            for src, data in images.items():
                z.writestr(f"OEBPS/{src}", data)
        os.replace(tmp, out_path)
    except Exception:
        if os.path.exists(tmp):
            os.remove(tmp)
        raise
```

```python
"""Ventana para convertir PDFs de novelas ligeras a EPUB."""
import html
import queue
import threading
import tkinter as tk
from pathlib import Path
from tkinter import filedialog, messagebox, ttk

import convert

ON, OFF = "✔", "✘"


class App:
    def __init__(self, root):
        self.root, self.book, self.pdf = root, None, None
        self.events = queue.Queue()  # los hilos de trabajo no tocan tkinter: envían eventos aquí
        root.title("PDF a EPUB")
        root.geometry("780x560")

        top = ttk.Frame(root, padding=8)
        top.pack(fill="x")
        self.open_btn = ttk.Button(top, text="Abrir PDF…", command=self.open_pdf)
        self.open_btn.pack(side="left")
        self.file_label = ttk.Label(top, text="Ningún archivo")
        self.file_label.pack(side="left", padx=8)

        meta = ttk.Frame(root, padding=(8, 0))
        meta.pack(fill="x")
        self.title_var, self.author_var = tk.StringVar(), tk.StringVar()
        ttk.Label(meta, text="Título:").pack(side="left")
        ttk.Entry(meta, textvariable=self.title_var, width=45).pack(side="left", padx=(4, 12))
        ttk.Label(meta, text="Autor:").pack(side="left")
        ttk.Entry(meta, textvariable=self.author_var, width=25).pack(side="left", padx=4)

        frame = ttk.Frame(root, padding=8)
        frame.pack(fill="both", expand=True)
        self.tree = ttk.Treeview(frame, columns=("inc", "title", "page"), show="headings", selectmode="browse")
        for col, text, width in (("inc", "Incluir", 60), ("title", "Capítulo", 560), ("page", "Página", 70)):
            self.tree.heading(col, text=text)
            self.tree.column(col, width=width, anchor="w" if col == "title" else "center", stretch=col == "title")
        scroll = ttk.Scrollbar(frame, orient="vertical", command=self.tree.yview)
        self.tree.configure(yscrollcommand=scroll.set)
        self.tree.pack(side="left", fill="both", expand=True)
        scroll.pack(side="right", fill="y")
        self.tree.bind("<Button-1>", self.on_click)
        self.tree.bind("<Double-1>", self.on_double_click)
        ttk.Label(root, text="Clic en Incluir: marcar o desmarcar · Doble clic en el título: editar",
                  padding=(8, 0)).pack(anchor="w")

        bottom = ttk.Frame(root, padding=8)
        bottom.pack(fill="x")
        self.progress = ttk.Progressbar(bottom, length=280)
        self.progress.pack(side="left")
        self.status = ttk.Label(bottom, text="")
        self.status.pack(side="left", padx=8)
        self.gen_btn = ttk.Button(bottom, text="Generar EPUB…", command=self.generate, state="disabled")
        self.gen_btn.pack(side="right")
        root.after(100, self.poll)

    def run(self, work, done):
        """Ejecuta work() en un hilo y llama a done(resultado) en el hilo de la ventana."""
        self.open_btn.state(["disabled"])
        self.gen_btn.state(["disabled"])

        def worker():
            try:
                self.events.put(("done", done, work()))
            except Exception as e:
                self.events.put(("error", e))

        threading.Thread(target=worker, daemon=True).start()

    def report(self, done, total):
        self.events.put(("progress", done, total))

    def poll(self):
        try:
            while True:
                event = self.events.get_nowait()
                if event[0] == "progress":
                    _, done, total = event
                    self.progress.configure(maximum=total, value=done)
                    self.status.configure(text=f"Analizando… {done * 100 // total} %")
                else:
                    self.open_btn.state(["!disabled"])
                    if self.book:
                        self.gen_btn.state(["!disabled"])
                    if event[0] == "done":
                        event[1](event[2])
                    else:
                        self.status.configure(text="Error")
                        messagebox.showerror("Error", str(event[1]))
        except queue.Empty:
            pass
        self.root.after(100, self.poll)

    def open_pdf(self):
        path = filedialog.askopenfilename(filetypes=[("PDF", "*.pdf")])
        if not path:
            return
        self.pdf, self.book = Path(path), None
        self.file_label.configure(text=self.pdf.name)
        self.tree.delete(*self.tree.get_children())
        self.run(lambda: convert.analyze(path, progress=self.report), self.show_book)

    def show_book(self, book):
        self.book = book
        self.title_var.set(book.title)
        self.author_var.set(book.author)
        for i in book.candidates:
            block = book.blocks[i]
            self.tree.insert("", "end", iid=str(i), values=(ON, html.unescape(block.html), block.page))
        self.gen_btn.state(["!disabled"])
        self.progress.configure(value=0)
        found = len(book.candidates)
        self.status.configure(text=f"{found} capítulos detectados" if found else
                              "No se detectaron capítulos: el EPUB tendrá una sola sección")

    def on_click(self, event):
        item = self.tree.identify_row(event.y)
        if item and self.tree.identify_column(event.x) == "#1":
            self.tree.set(item, "inc", OFF if self.tree.set(item, "inc") == ON else ON)

    def on_double_click(self, event):
        item = self.tree.identify_row(event.y)
        if not item or self.tree.identify_column(event.x) != "#2":
            return
        x, y, w, h = self.tree.bbox(item, "title")
        entry = ttk.Entry(self.tree)
        entry.insert(0, self.tree.set(item, "title"))
        entry.select_range(0, "end")
        entry.place(x=x, y=y, width=w, height=h)
        entry.focus()

        def save(_=None):
            if entry.get().strip():
                self.tree.set(item, "title", entry.get().strip())
            entry.destroy()

        entry.bind("<Return>", save)
        entry.bind("<FocusOut>", save)
        entry.bind("<Escape>", lambda _: entry.destroy())

    def generate(self):
        out = filedialog.asksaveasfilename(defaultextension=".epub", filetypes=[("EPUB", "*.epub")],
                                           initialdir=self.pdf.parent, initialfile=self.pdf.stem + ".epub")
        if not out:
            return
        self.book.title = self.title_var.get().strip() or self.pdf.stem
        self.book.author = self.author_var.get().strip()
        chapters = [(int(item), self.tree.set(item, "title")) for item in self.tree.get_children()
                    if self.tree.set(item, "inc") == ON]
        self.status.configure(text="Generando EPUB…")
        self.run(lambda: convert.write_epub(self.book, chapters, out), lambda _: self.saved(out))

    def saved(self, out):
        self.status.configure(text=f"Guardado: {Path(out).name}")
        messagebox.showinfo("Listo", f"EPUB guardado en:\n{out}")


if __name__ == "__main__":
    root = tk.Tk()
    App(root)
    root.mainloop()
```
