# Entrega F Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enviar al móvil por Wi-Fi con QR, añadir a Calibre, portada con título, fuente propia y avisos de
texto sin traducir y erratas típicas.

**Architecture:** Lo del libro va en `convert.py` (`quality_report`, `text_cover`, `write_epub(font=ruta)`);
lo del equipo en `app.py` (`_lan_ip`, `_serve`, `_calibre`, botones de «EPUB listo», «Elegir portada» y
combo «Letra»).

**Tech Stack:** Python 3.14, PyMuPDF, PySide6, `segno` (nuevo, QR en Python puro).

**Spec:** `docs/superpowers/specs/2026-10-31-entrega-f-design.md`

## Global Constraints

- Texto visible y comentarios en español con tildes; identificadores en inglés.
- Cada cambio de `convert.py` lleva prueba en `test_convert.py`.
- Las pruebas existentes siguen pasando. Suite: `.venv/Scripts/python.exe test_convert.py`.
- Commits en inglés, Conventional Commits. Al final, `/build-exe`.

## Review Focus

- Pregunta ya bien escrita, con `¿` a mitad de frase («Oye, ¿qué haces?») o `¡¿…?!`: sin aviso (Task 2).
- «haber» legítimo («va a haber», «tiene que haber sitio»): sin aviso (Task 2).
- Párrafo español con palabras inglesas sueltas («OK», «game over», nombres): sin aviso (Task 1).
- Fuente propia borrada tras guardar la revisión: vuelve a «Del lector», no rompe al generar (Task 4).
- `.exe` sin consola: el servidor no escribe en `stderr` (es `None`) (Task 5).

- [ ] Prueba `test_quality_report_fixes_fansub_typos`: párrafos «Qué haces? —preguntó. Ven aquí!»,

  «A ver si llegas pronto.», «¿Por qué lo hiciste?». Cursiva: «<i>Qué haces?</i>» queda «<i>¿Qué haces?</i>».

```python
SENTENCE = re.compile(r"([^.…!?»—]*?)([?!]+)")  # una oración que acaba en ? o !, desde el corte anterior
LEAD = re.compile(r"(?:\s|[«“\"'(]|</?[ib]>)*")   # lo que va antes de la primera palabra
DOUBLED = re.compile(r"\b(de|la|el|que|en|y|los|las|un|una|por|con|se|lo) \1\b", re.I)


def _opening_marks(line):
    """Pone ¿ o ¡ al principio de las oraciones que solo llevan el signo de cierre ("Qué haces?")."""
    def fix(m):
        body, close = m[1], m[2]
        if "¿" in body or "¡" in body or not any(c.isalpha() for c in body):
            return m[0]
        lead = LEAD.match(body).end()
        return body[:lead] + ("¿" if close[0] == "?" else "¡") + body[lead:] + close
    return SENTENCE.sub(fix, line)


TYPOS = (  # (tipo, título, arreglo de la línea, por qué): erratas típicas de las traducciones fan
    ("opening", "Falta el signo de apertura", _opening_marks,
     "En español las preguntas y exclamaciones llevan signo de apertura (¿ ¡) además del de cierre."),
    ("doubled", "Palabra repetida", lambda s: DOUBLED.sub(r"\1", s),
     "La misma palabra dos veces seguidas suele ser un error al escribir."),
    ("aver", "«Haber si» en vez de «a ver si»",
     lambda s: re.sub(r"(^|[¿¡—«“\"(.…]\s*)([Hh])aber si\b",
                      lambda m: m[1] + ("A" if m[2] == "H" else "a") + " ver si", s),
     "«A ver si» (del verbo ver) se confunde a menudo con «haber»."),
    ("porque", "«¿Porque» en vez de «¿por qué»", lambda s: re.sub(r"¿([Pp])orque\b", r"¿\1or qué", s),
     "En una pregunta va «por qué», separado y con tilde."),
)
```

```python
def text_cover(book):
    """Portada dibujada con serie, volumen, título y autor, para cuando el PDF no trae una buena. El color
    del fondo sale de la serie: todos los tomos de una serie comparten color."""
    hue = zlib.crc32((book.series or book.title).encode()) % 360 / 360
    with pymupdf.open() as doc:
        page = doc.new_page(width=600, height=900)
        page.draw_rect(page.rect, color=None, fill=colorsys.hls_to_rgb(hue, 0.22, 0.45))
        page.insert_font("bold", fontfile=str(FONT_DIR / "literata-700-normal.ttf"))

                                       ((50, 300, 550, 680), book.title, "bold", 64),
                                       ((50, 740, 550, 850), book.author, "text", 28)):
            while text and size > 10 and page.insert_textbox(rect, text, fontname=font, fontsize=size,
```

```python
def _lan_ip():
    """IP de este equipo en la red local: la de la ruta por defecto. Conectar un socket UDP no envía nada."""
    with socket.socket(socket.AF_INET, socket.SOCK_DGRAM) as s:
        try:
            s.connect(("10.255.255.255", 1))
            return s.getsockname()[0]
        except OSError:
            return "127.0.0.1"


def _serve(path, host):
    """Sirve el EPUB por HTTP (cualquier ruta lo devuelve) en un puerto libre, desde un hilo: solo lee un
    archivo, no usa PyMuPDF. server.shutdown() lo para."""
    data, name = Path(path).read_bytes(), Path(path).name

    class Handler(http.server.BaseHTTPRequestHandler):
        def do_GET(self):
            self.send_response(200)
            self.send_header("Content-Type", "application/epub+zip")
            self.send_header("Content-Disposition", f"attachment; filename*=UTF-8''{urllib.parse.quote(name)}")
            self.send_header("Content-Length", str(len(data)))
            self.end_headers()
            self.wfile.write(data)

        def log_message(self, *args):
            pass  # el .exe no tiene consola: escribir en stderr (None) fallaría

    server = http.server.ThreadingHTTPServer((host, 0), Handler)
    threading.Thread(target=server.serve_forever, daemon=True).start()
    return server
```

```python
def _calibre():
    """calibre.exe si está instalado: en el PATH o en su carpeta de siempre."""
    found = shutil.which("calibre")
    for var in ("ProgramFiles", "ProgramFiles(x86)"):
        if not found and os.environ.get(var) and (Path(os.environ[var]) / "Calibre2" / "calibre.exe").is_file():
            found = str(Path(os.environ[var]) / "Calibre2" / "calibre.exe")
    return found
```
