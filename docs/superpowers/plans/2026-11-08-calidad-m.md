# Entrega M (calidad) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Avisos nuevos en el informe de calidad: raya de cierre del inciso, calcos del inglés, mayúsculas de más, signos sin pareja y repetidos, ecos (opcional) y glosario de la serie.

**Architecture:** Reglas nuevas en `TYPOS` (las que se arreglan reescribiendo la línea) y comprobaciones nuevas en el bucle de `quality_report` (las que no). `quality_report(book, echoes=False, glossary=())`. En `app.py`: casilla «Buscar ecos» en el diálogo de calidad (preferencia `echoes`) y diálogo «Glosario…» (campo `glossary`, heredado entre tomos).

**Tech Stack:** Python 3.14, `re`, PySide6.

**Spec:** `docs/superpowers/specs/2026-11-08-edicion-profesional-design.md` (sección M)

- Cada aviso con su test en `test_convert.py`, con casos que avisan y parecidos que no.

## Notas del código actual

- El punto antes del inciso («—Hola. —dijo» → «—Hola —dijo») **ya lo arregla** la entrada `"dialog"` de `TYPOS` (`_inciso`). Solo falta la raya de cierre.
- `_typos` descarta los arreglos que la limpieza tipográfica del EPUB ya hace: una regla nueva no debe duplicarlos.
- `_issue_span` subraya en el editor; los avisos sin `edit` necesitan su rama ahí, o se subraya el párrafo entero.

## Review Focus

- Inciso seguido de narración, no de diálogo («—Ven —dijo él. Luego se fue»): con la regla de raya de cierre se avisaría mal; medir en la regresión y, si es ruidoso, quitar la regla (Task 1).
- Cita de varios párrafos («…sin cerrar» y el siguiente empieza por «»»): no avisa (test en Task 4).
- Emoticonos «:)» y enumeraciones «a)» en chats: no avisan de paréntesis (test en Task 4).
- «el Señor Demonio», «el Rey Demonio»: no se tocan (test en Task 3).
- Nombre que ya está en el glosario con dos formas (el usuario añadió las dos): no avisa (test en Task 6).

def _aside_close(s):

- [ ] Función y aviso:

```python
PAIRS = (("«", "»"), ("“", "”"), ("(", ")"))

@_memo
def _unpaired(text):
    """Posición del primer signo sin pareja del párrafo («, “ o ( sin cerrar, o el cierre sin abrir), o None.
    Sin contar emoticonos «:)» ni enumeraciones «a)»."""
    clean = re.sub(r"[:;]-?\)|(?:^|\s)[a-z0-9]\)", lambda m: " " * len(m[0]), text)
    for a, b in PAIRS:
        depth, first = 0, None
        for i, c in enumerate(clean):
            if c == a:
                depth, first = depth + 1, first if depth else i
            elif c == b:
                if not depth:
                    return i, a, False
                depth -= 1
        if depth:
            return first, a, True
    return None
```

En el bucle, tras `"english"`: si `_unpaired(text)` da `(pos, sign, open_)` y no es (`sign == "«"` y el párrafo siguiente empieza por « o »  si `open_`, o este empieza por « o » si no `open_`) → `Issue("unpaired", k, b.page, "Revisar", "Signo sin pareja", "Se abre «…» o un paréntesis y no se cierra (o al revés): falta un signo o sobra.", "Compáralo con el PDF y corrígelo con «Editar texto…» (tecla E).", _around(text, pos, pos + 1), text=text)`.

En `_issue_span`: `if issue.kind == "unpaired": pos = _unpaired(text)[0]; return lead + pos, lead + pos + 1`.

- [ ] Implementar:

```python
ECHO_SKIP = set("cuando porque entonces también estaba estaban había habían tenía tenían puede pueden "
                "quiero quería sobre desde hasta donde mientras siempre todavía mucho mucha muchos muchas "
                "nuestro nuestra algún alguna alguien nadie nada cosas parece podía después antes ahora "
                "aquí estoy estás están eres somos fueron siendo hacia contra otros otras tanto".split())

@_memo
def _echo(text):
    """(inicio, fin) de la segunda de dos palabras iguales a menos de 12 palabras, o None. En minúscula (los
    nombres se repiten a propósito), de 5 letras o más y no vacías; a menos de 3 es repetición buscada."""
    seen = {}
    for n, m in enumerate(re.finditer(r"[^\W\d_]+", text)):
        w = m[0]
        if len(w) < 5 or not w.islower() or w in ECHO_SKIP:
            continue
        if w in seen and 3 <= n - seen[w] <= 12:
            return m.span()
        seen[w] = n
    return None
```
